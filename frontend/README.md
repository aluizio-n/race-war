# Race War — Frontend

Mobile app built with Expo (SDK 54) and React Native.

## Stack

- [Expo](https://expo.dev) SDK 54 / React Native 0.81
- [Expo Router](https://expo.github.io/router) v6 (file-based routing)
- [NativeWind](https://www.nativewind.dev) v4 (Tailwind CSS for React Native)
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated) v4
- [React Native Maps](https://github.com/react-native-maps/react-native-maps)

## Getting Started

```bash
cd frontend
npm install --legacy-peer-deps
npx expo start
```

Scan the QR code with [Expo Go](https://expo.dev/go) on your device.
